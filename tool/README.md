# robot_lab 专用工具与命令脚本库 (Toolbox & Utilities)

> **目录定位**：根据强化学习工程规范（参见 `/home/rum/isaac/agent.md` 核心规则 4），本目录专门存放所有辅助运维、状态诊断、格式转换、命令包装与环境自检工具脚本，杜绝污染核心训练源码 (`source/robot_lab`) 与主执行目录 (`scripts/`)。

## 规范约定
1. 任何诊断、可视化、测试、数据提取、快捷启动等辅助性脚本统一放入本目录；
2. 严禁在根目录或训练业务包中随意抛撒一次性脚本；
3. 本目录下脚本均设计为无副作用独立执行，支持直接通过 Python 调用。
